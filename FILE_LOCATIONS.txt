WHAT YOU EDITED & WHY

What changed:

  TO:   python -u scripts/10_trial_pipeline_check.py \

Why:
  - Python was buffering output (4KB blocks) instead of printing real-time
  - When piping to "tee", Python doesn't detect a TTY, so no output visible
  - The "-u" flag forces unbuffered output (print immediately)
  - Now you see progress as episodes complete
