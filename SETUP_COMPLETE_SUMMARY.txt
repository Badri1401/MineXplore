ENVIRONMENT SPECIFICATIONS
════════════════════════════════════════════════════════════════════════════════

Robot:
  • Radius: 0.35 m
  • Max velocity: 1.5 m/s forward/backward
  • Max rotation: 1.5 rad/s
  • Action space: 2D [velocity, omega] ∈ [-1.5, 1.5]²

Sensors:
  • LiDAR: 360 beams, 0.12-30m range
  • Noise: 0.005m Gaussian, 2% dropout
  • Observations: 24D vector (goal, lidar, velocity)

Physics:
  • Timestep: 0.005 seconds
  • Collision penalty: -10.0
  • Goal bonus: +10.0

Reward:
  • 90% milestones (25%, 50%, 75%, 100% coverage)
  • 10% progress per step
  • Collision detection with walls

Spawn Modes:
  • local_curriculum: Anywhere in tunnel (easiest)
  • ae_feasible: A↔E opposite ends (medium)
  • ae_opposite: Strict A↔E (hard)
  • auto_feasible: Auto-curriculum (default)

TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Problem: "No module named 'mining_env'"
Solution:
  export PYTHONPATH=~/mining_env_dataset_folder/mining_env_complete:$PYTHONPATH
  python your_script.py

Problem: "FileNotFoundError: chilean_mine_geometry.xml"
Solution:
  ls mining_env_complete/outputs/chilean_mine_geometry.xml
  If missing, the file wasn't copied correctly.

Problem: Training script hangs (no output)
Solution:
  Use unbuffered output:
  python -u rl_training.py --episodes 100

Problem: Out of memory
Solution:
  Reduce episodes or memory:
  ./RUN_TRAINING.sh --episodes 1000 --summary-window 50

Problem: Rock meshes not found
Solution:
  ls mining_env_complete/outputs/meshes/*.obj | wc -l
  Should show ~1186. If less, meshes weren't copied completely.
