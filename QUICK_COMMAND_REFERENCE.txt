✨ KEY PARAMETERS EXPLAINED
════════════════════════════════════════════════════════════════════════════════════════════════

--episodes 30000           How many episodes to run (default: 30000)
--max-steps 6000          Max steps per episode (default: 6000)
--policy explore          Policy type: 'explore' or 'random' (default: explore)
--print-every 10          Print progress every N episodes (default: 10)
--plot-every 5000         Refresh plots every N episodes (default: 5000)
--summary-window 100      Window for rolling stats (default: 100)
--run-dir outputs/...     Output directory (default: outputs/trial_runs)
